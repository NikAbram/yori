# YŌRI — визуальная концепция этапа 1

## Идея

Интерфейс соединяет тёмную сервировочную поверхность и тёплую бумагу меню. Главный выразительный приём — крупное асимметрично кадрированное блюдо с радиусом, напоминающим край тарелки. Остальная система намеренно спокойная: без декоративной псевдояпонской графики, случайных градиентов и набора одинаковых SaaS-карточек.

## Токены

| Роль | Значение |
|---|---|
| Угольный / основной текст | `#171411` |
| Тёплый молочный / фон | `#F4EFE6` |
| Бумажный / поднятая поверхность | `#FFF9F0` |
| Томатный / действие | `#D64A32` |
| Листовой / спокойный статус | `#55705A` |
| Янтарный / предупреждение | `#C88736` |

Семантические цвета, тени, safe-area и темы объявлены CSS-переменными в `src/app/globals.css`. Радиусы меняются по иерархии: компактные controls, мягкие карточки и выраженный внешний угол у ключевых поверхностей.

## Типографика

- Georgia / Times New Roman — названия, крупные заголовки и цены; кириллица поддерживается системно и не требует загрузки внешнего шрифта.
- Inter / Segoe UI / Arial — управление и поясняющий текст.
- Заголовки выровнены влево; центрирование применяется только в состояниях без контента.

## Фото и композиция

- крупное предметное кадрирование без логотипов ресторанов;
- `object-fit: cover` и заранее заданные пропорции предотвращают layout shift;
- описание источников и текущие ограничения находятся в `ASSET_SOURCES.md`.

## Motion и доступность

- движение используется только как ответ на hover/action;
- `prefers-reduced-motion` отключает переходы и shimmer;
- все основные controls имеют доступные имена, видимый focus и мобильный размер;
- нижняя навигация и контейнер учитывают CSS safe-area.

## Самопроверка на шаблонность

Убраны декоративные labels без функции, равные радиусы на всех уровнях, градиентные украшения и каскадные entrance-анимации. Визуальная идентичность держится на фотографии, контрасте «уголь/бумага» и характерной форме ключевых поверхностей.
