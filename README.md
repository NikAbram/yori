# YŌRI

Клиентская основа Telegram Mini App доставки суши и роллов. Текущий статус: завершена часть 2.2 — каталог, товар, локальная корзина, безопасные состояния заказов и профиля, справочные страницы и checkout с локальной валидацией на React Hook Form и Zod.

## Команды

```bash
npm run dev
npm run lint
npm run typecheck
npm run test
npm run test:e2e
npm run build
```

Серверные заказы, Telegram-аутентификация, Neon, Prisma и CRM ещё не подключены. Приём заказов закрыт, личные данные вне подтверждённой Telegram-сессии не показываются. Checkout проверяет ввод только локально, ничего не отправляет и не имитирует создание заказа.
