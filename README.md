# YŌRI

Клиентская основа Telegram Mini App доставки суши и роллов. Текущий статус: этап 2 завершён — каталог, локальная корзина, checkout и личные разделы адаптированы к Telegram и обычному браузеру, проверены на доступность, светлой и тёмной темах и целевых ширинах 320–1440 px.

Для UI-QA используются Playwright и `@axe-core/playwright`: проверяются основные маршруты, клавиатурная навигация, WCAG A/AA, состояния интерфейса, изображения, горизонтальный скролл и перекрытия фиксированной навигацией.

## Команды

```bash
npm run dev
npm run lint
npm run typecheck
npm run test
npm run test:e2e
npm run build
```

Серверные заказы, Telegram-аутентификация, Neon, Prisma и CRM ещё не подключены. UI-интеграция Telegram не является авторизацией и не использует `initDataUnsafe`: приём заказов закрыт, личные данные не показываются, а checkout проверяет ввод только локально и ничего не отправляет.
