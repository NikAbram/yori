# YŌRI

Клиентская основа Telegram Mini App доставки суши и роллов. Текущий статус: завершена часть 2.1 — каталог, товар, локальная корзина, безопасные состояния заказов и профиля, а также справочные страницы на типизированных данных-заготовках.

## Команды

```bash
npm run dev
npm run lint
npm run typecheck
npm run test
npm run test:e2e
npm run build
```

Серверные заказы, Telegram-аутентификация, Neon, Prisma и CRM ещё не подключены. Приём заказов закрыт, личные данные вне подтверждённой Telegram-сессии не показываются, checkout пока содержит безопасное информационное состояние.
