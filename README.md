# YŌRI

Клиентская основа Telegram Mini App доставки суши и роллов. Текущий статус: этап 1 — визуальная концепция, каталог, товар и локальная корзина на данных-заготовках.

## Команды

```bash
npm run dev
npm run lint
npm run typecheck
npm run test
npm run test:e2e
npm run build
```

Серверные заказы, Telegram-аутентификация, Neon, Prisma и CRM не входят в этап 1. Приём заказов закрыт, checkout показывает безопасное информационное состояние.
